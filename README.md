# Test Contour

> Код производит XSLT-преобразование файлов Data1.xml и Data2.xml в XML файл той же структуры, что и Employees.xml. Результат преобразования выводится в окне.

## Загрузка

`git clone https://github.com/VortexOwl/contour-test-task.git`

## Установка зависимостей

Для работы скрипта требуется скачать и установить [.NET SDK](https://dotnet.microsoft.com/ru-ru/download) и Avalonia:

`dotnet new install Avalonia.Templates`

## Запуск

Перейдите в папку проекта и активируйте команду:

`dotnet run`

## Структура

В папке data хранятся исходные файлы тестового задания.
В папке docs находится тестовое задание.
В папку result сохраняются результаты решения заданий.
В папке src находится код решения.

## Описание процесса программы

При запуске открывается окно решения тестового задания.

Сверху динамически появляется информация содержащая список всех Employee и сумму всех выплат по месяцам, включая общую сумму выплат.
Данный блок будет отсутствовать, если в папке result отсутствует файл решения Employees1_v2.xml.

Затем представлен блок добавления данных в Data1.xml, который реализует решение необязательного пункта 5 тестового задания.
После ввода данных в соответствующие поля и нажатия на кнопку "Добавить" происходит добавление этих данных в Data1.xml.
Если передать поле с некорректным значением, то добавление данных не будет произведено.

Внизу находится кнопка "Запустить", при нажатии на которую происходит XSLT-преобразование файлов Data1.xml и Data2.xml в Employees1.xml и Employees2.xml соответственно.
Затем происходит добавление в Employee атрибута, который отражает сумму всех amount/@salary этого элемента и сохранение результата в Employees1_v2.xml и Employees2_v2.xml **соответственно**.
Далее происходит выполнения пункта 3 тестового задания, а именно добавления общей суммы amount элементов item в новый атрибут Pay с сохранением результата в Data1_v2.xml в папке result.
